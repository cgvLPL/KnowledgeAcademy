# Changelog

All notable changes to CGV Knowledge Academy are documented in this file.

## [1.1.3] - 2026-08-12

### Fixed

- Made the **Add to calendar** and **Not open yet** controls span the full
  scheduled-evaluation card on participant phones.
- Kept the complete action group in the dedicated tablet grid column so both
  controls remain aligned between mobile and desktop layouts.

### Quality

- Added regression coverage for tablet and mobile action-container placement.

## [1.1.2] - 2026-08-11

### Added

- Participant and course filtering, safe CSV exports, scheduled evaluation
  calendar files, and participant score trends.

### Changed

- Refreshed the participant and administrator productivity workflows without
  requiring a Google Apps Script deployment.
