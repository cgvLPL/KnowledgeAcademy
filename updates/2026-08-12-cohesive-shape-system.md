# Cohesive interface shape system — 2026-08-12

## Improved

- Introduced a shared shape hierarchy for hero surfaces, panels, repeating cards, controls, compact icon controls, modals, and semantic pills.
- Standardized participant and administrator cards so evaluation rows, course cards, metric cards, profile cards, settings surfaces, tables, and quiz/editor panels feel visually related.
- Standardized buttons, sidebar actions, mobile navigation, filters, form fields, and selectors around the same control radius.
- Preserved intentionally circular elements such as avatars, score rings, progress rings, and answer radio indicators.
- Added mobile-specific panel/modal sizing so the same shape language remains cohesive on phones without feeling oversized.
- Added regression coverage to ensure the final shape layer stays loaded after historical release styles.

- No Google Apps Script changes are required.
